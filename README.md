# けんちゃんサンキュー鉄道旅

サンキューちばフリーパスで千葉の鉄道を2日間乗り倒す、**スマホ用の行程表**です。

**→ https://moracchi.github.io/kenchan-chiba-rail/**

## 行程

| | ルート | 出発 → 帰着 |
|---|---|---|
| **1日目** | 小湊鉄道＋トロッコ漬け（船橋・五井・養老渓谷） | 7:19 → 16:37頃 |
| **2日目** | 7路線級・銚子ループ（東葉高速・京成・成田線・銚子電鉄・総武本線） | 6:55 → 17時前後 |

## 旅先で使う機能

- **いまここ** — 現在時刻から、その日の次に乗る列車まで自動スクロール
- **「のった？」スタンプ** — 乗車ごとにタップでチェック。`localStorage` に保存されるので閉じても消えません
- 追従バーに現在時刻と1日目／2日目タブ
- ダークモード対応、オフラインでも図版が表示されます（画像はすべてインライン SVG）

## ファイル

| ファイル | 用途 |
|---|---|
| `kenchan-chiba-rail.html` | **編集するのはこちら。** Claude Artifact 用のフラグメント（`<head>` を持たない） |
| `index.html` | GitHub Pages が配信する完全な HTML 文書。`build.ps1` が生成するので直接編集しない |
| `build.ps1` | 上を下に変換するスクリプト |

ページを直したら、フラグメントを編集してから:

```powershell
pwsh ./build.ps1
```

## 出発前の確認事項

- **小湊鉄道は復旧途中**です。運転状況を直前に確認してください
- **房総里山トロッコの指定席券 800円**はフリーパスとは別に必要です
- 2日目、**銚子 9:56着 → 10:00発の乗換4分**が山場です

時刻は計画時点のものです。
