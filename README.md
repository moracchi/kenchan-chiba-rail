# けんちゃんサンキューフリーパス鉄道旅行

サンキューちばフリーパスで千葉のローカル線を2日間めぐる、**スマホ用の行程表**です。

**→ https://moracchi.github.io/kenchan-chiba-rail/**

## 行程

| | ルート | 出発 → 帰着 |
|---|---|---|
| **1日目** | 小湊鉄道＋房総里山トロッコ（船橋 → 五井 → 上総牛久 → 養老渓谷） | 7:19 → 16:48 |
| **2日目** | 銚子ループ（東海神 → 東葉高速 → 京成 → 成田線 → 銚子電鉄 → 総武本線） | 7:17 → 16:58 |

日程はシルバーウィークの連続2日で、日付は未定。9/19（土）〜9/23（水・祝）はどの2日を選んでも土休日ダイヤなので、時刻はそのまま使えます。

## 旅先で使う機能

- **日程セレクタ** — 9/19・20／9/20・21／9/21・22／9/22・23／まだ未定 から選ぶと各日の日付表示が変わります。選択は `localStorage` に保存
- **「つぎ」マーカー** — 現在時刻から次に着く駅を自動で色づけ。旅の途中に開くとそこまでスクロールします
- **チェックオフ** — 乗車・散策の各行をタップで済みにできます（こちらも `localStorage` 保存、「じゅんび」タブに全消しボタン）
- 1日目／2日目／じゅんび の3タブが画面上部に追従
- ダークモード対応。図版はすべてインライン SVG なので、電波が弱くても表示されます

## ファイル

| ファイル | 用途 |
|---|---|
| `kenchan-chiba-rail.html` | **編集するのはこちら。** Claude Artifact 用のフラグメント（`<head>` を持たない） |
| `index.html` | GitHub Pages が配信する完全な HTML 文書。`build.ps1` が生成するので直接編集しない |
| `build.ps1` | 上を下に変換するスクリプト |

ページを直したら、フラグメントを編集してから:

```powershell
pwsh ./build.ps1
```

PowerShell 7 が入っていない環境では、Windows PowerShell 5.1 でも動きます:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

## 出発前の確認事項

- **小湊鉄道は復旧途中**です。9/1 時点では里見〜上総中野が代行バス。「9月中旬〜9月末の休日は五井〜上総中野を終日 列車運転」という計画なので、出発の3日前くらいに運転状況を確認してください
- **房総里山トロッコの運転日**を確認し、**指定席券 800円／人**を別途確保（フリーパスには含まれません）
- 2日目、**銚子 9:56着 → 10:00発の乗換4分**が山場です。逃したときのプランBはページ内にあります

時刻は計画時点のものです。
